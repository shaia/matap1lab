# מתמטיקה שימושית 1 — ספר לימוד חי

קורס אינטראקטיבי בעברית ללימוד עצמי של הכלים המתמטיים שלומדים בסמסטר הראשון של התואר בפיזיקה, לפי הסילבוס של
הקורס **80114 "מתמטיקה שימושית (1)"** באוניברסיטה העברית: וקטורים וגיאומטריה ב-ℝⁿ, מערכות קואורדינטות, מספרים
מרוכבים, פונקציות של משתנה אחד, נגזרות, טורי טיילור, אינטגרלים לא מסוימים ומסוימים, עקומות, פונקציות של כמה משתנים
(גרדיאנט, כלל השרשרת, קיצון, כופלי לגרנז'), שדות וקטוריים ואינטגרלים קוויים, ואינטגרלים כפולים ומשולשים. הדגש הוא
על הבנה אינטואיטיבית ועל שימוש, יותר מאשר על הוכחות.

לכל פרק יש מסלול מדורג: **שאלות הבנה** לכל שיעור (בסיס, בינוני, מבחן), **שאלות חזרה** על כל הפרק, **שאלות מבחן**
עם פתרון מלא ומחוון להערכה עצמית, ו**מבחן פרק** מוגרל עם דוח.

הקורס בנוי על הפלטפורמה של קורסי האחות (emlab, infilab, advinfilab, unimech): Astro 7, Preact, MDX ו-KaTeX, בעיצוב
של "ספר חי".

```powershell
npm install
npm run dev            # http://localhost:4321
npx vitest run         # math + unit tests
npm run lint:content   # schemas, TeX, objectives, question-bank completeness
npm run build          # static site -> dist/
npm run e2e            # Playwright against the preview server on :4391
```
